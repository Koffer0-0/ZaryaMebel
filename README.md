# Мебель на заказ · Астана — лендинг

Статический сайт. Чистый HTML + CSS + vanilla JS, без сборки и без бэкенда.
Просто загрузите папку на хостинг — работает как есть.

```
index.html            вся разметка + SEO-теги + структурированные данные
css/styles.css        стили (палитра меняется в блоке :root вверху файла)
js/gallery-data.js    ← ФОТО ПОРТФОЛИО добавляются только здесь
js/main.js            меню, фильтры, лайтбокс, форма → WhatsApp
img/hero.svg          главное фото (заменить на hero.jpg)
img/og-cover.svg      картинка превью для WhatsApp/соцсетей
img/portfolio/        фото работ
robots.txt
sitemap.xml
.htaccess             кэш + gzip для Apache-хостингов
favicon.svg
serve.js              только для локального просмотра, на хостинг не нужен
```

### Посмотреть локально

```bash
node serve.js
```

Откроется на `http://localhost:4173`. Просто открыть `index.html` двойным
кликом тоже можно, но через `file://` часть браузеров блокирует загрузку
`gallery-data.js` — поэтому лучше через сервер.

## Шаг 1. Добавить фото из Instagram

Всё в одном файле — **`js/gallery-data.js`**. Инструкция есть в комментарии
сверху этого файла и в `img/portfolio/README.txt`. Коротко:

1. Сожмите фото: **`.webp` или `.jpg`, ширина 1200–1600 px, до 250 КБ**
   (быстро: [squoosh.app](https://squoosh.app) или [tinypng.com](https://tinypng.com)).
   Тяжёлые фото прямо из Instagram — главная причина медленной загрузки
   и просадки в поиске.
2. Положите файлы в `img/portfolio/`, имена латиницей: `kitchen-01.jpg`.
3. Добавьте блок в список:

```js
{
  src:  'img/portfolio/kitchen-01.jpg',
  alt:  'Белая угловая кухня с фасадами МДФ, Астана',
  cat:  'kitchen',
  title:'Кухня в ЖК «Хайвилл»',
  note: 'МДФ, столешница акрил, 3,2 м'
},
```

Категории `cat`: `kitchen`, `wardrobe`, `cabinet`, `other` — совпадают
с фильтрами на странице.

`alt` пишите по-русски и по делу — это то, по чему вас найдут в поиске
по картинкам. Порядок в списке = порядок на сайте, лучшие работы ставьте наверх.

Главное фото замените на `img/hero.jpg` (вертикальное, ~1200×1400) и поправьте
`src` в `index.html` — оно там одно, в блоке `.hero__media`.

## Шаг 2. Прописать домен (обязательно для SEO)

Пока в файлах стоит заглушка `example.kz`. Замените её на свой домен
в трёх местах:

| Файл | Что заменить |
|---|---|
| `index.html` | `<link rel="canonical">`, все `og:*`, и блок JSON-LD внизу файла (`@id`, `url`, `image`) |
| `robots.txt` | строка `Sitemap:` |
| `sitemap.xml` | `<loc>` |

Быстрая замена по всему проекту в редакторе: найти `example.kz` → заменить
на свой домен. Проверьте, что нигде не осталось.

## Шаг 3. Проверить и заменить тексты

Обязательно сверьте с реальностью — сейчас там разумные значения по умолчанию,
но подтвердить их должны вы:

- [ ] **Название компании.** В шапке и подвале сейчас логотип-заглушка
      «МЕБЕЛЬ на заказ / Астана». Ищите комментарий `ЛОГОТИП` в `index.html`.
- [ ] **Часы приёма заявок** — сейчас «Ежедневно 09:00–20:00»
      (в разделе контактов, в подвале и в JSON-LD `openingHoursSpecification`).
- [ ] **Гарантия и оплата** — в FAQ написано «гарантийные условия в договоре»
      и «аванс + остаток после монтажа». Впишите свои условия.
- [ ] **Материалы и фурнитура** — в разделе «Материалы» указано обобщённо
      («проверенных марок»). Если работаете с конкретными брендами
      (Blum, Hettich, Egger и т.п.) — назовите их, это повышает доверие.
- [ ] **Адрес / шоурум.** Если есть физический адрес, добавьте `streetAddress`
      в JSON-LD и в раздел контактов — это сильно помогает в локальном поиске.
- [ ] **Отзывы.** Секции отзывов нет намеренно: настоящие отзывы полезны,
      выдуманные — вредны и для доверия, и для Google. Когда наберёте реальные
      (со скриншотами из WhatsApp или 2GIS) — добавим блок.

шапка, hero, портфолио, материалы, контакты, форма, подвал, плавающая кнопка

## Шаг 4. Выложить на хостинг

Сайт статический, поэтому подходит почти всё.

**Бесплатно, с HTTPS и своим доменом:**

- **Netlify** — [app.netlify.com/drop](https://app.netlify.com/drop),
  перетащить папку в браузер. Домен подключается в Domain settings.
- **Cloudflare Pages** — то же самое, плюс быстрый CDN и хорошая скорость в KZ.
- **GitHub Pages** — если удобнее через git.

**Обычный хостинг (PS.KZ, Hoster.kz, cPanel):** залейте содержимое папки
в `public_html` по FTP. Файл `.htaccess` уже настроен на сжатие и кэш —
там же закомментированы правила «force HTTPS» и «убрать www»,
раскомментируйте их после подключения домена.

## Шаг 5. После публикации — SEO-минимум

1. **Google Search Console** — [search.google.com/search-console](https://search.google.com/search-console):
   добавить сайт, подтвердить, отправить `sitemap.xml`.
2. **Яндекс.Вебмастер** — [webmaster.yandex.ru](https://webmaster.yandex.ru):
   то же самое. В KZ Яндекс даёт заметный трафик.
3. **Google Business Profile** — [business.google.com](https://business.google.com):
   для запросов «мебель на заказ Астана» карточка организации часто важнее
   самого сайта. Заполните категорию «Изготовление мебели», добавьте фото
   тех же работ и ссылку на сайт.
4. **2GIS** — добавьте организацию, там ищут мебельщиков в Астане.
5. **Проверка страницы:**
   - разметка → [search.google.com/test/rich-results](https://search.google.com/test/rich-results)
     (должны найтись `FurnitureStore` и `FAQPage`)
   - скорость → [pagespeed.web.dev](https://pagespeed.web.dev)
     (если оценка низкая — почти всегда виноват вес фото, см. шаг 1)
6. **Ссылку на сайт** поставьте в шапку профиля Instagram.

## Что уже сделано для SEO

- `lang="ru"`, один `<h1>`, дальше корректная иерархия `h2`/`h3`
- `title` и `description` с городом и ключевыми запросами
- canonical, `robots`, geo-теги на Астану
- Open Graph + Twitter Card — красивое превью при отправке ссылки в WhatsApp
- JSON-LD: `FurnitureStore` (телефон, город, часы работы, каталог услуг),
  `WebSite`, `FAQPage` — блок «Вопросы» может попасть в выдачу Google раскрытым
- семантическая разметка: `header`, `main`, `section`, `article`, `nav`, `footer`
- FAQ на нативных `<details>` — текст ответов индексируется даже в закрытом виде
- `alt` у всех изображений, `width`/`height` заданы (нет скачков вёрстки)
- ленивая загрузка фото начиная с 7-го, `fetchpriority="high"` на главном
- ноль внешних библиотек — грузится только шрифт Manrope

## Доступность и адаптив

- работает на телефоне: мобильное меню, нижняя панель «Позвонить / WhatsApp»
- лайтбокс с клавиатуры (`←` `→` `Esc`) и свайпом на телефоне
- фокус видно на всех интерактивных элементах, есть skip-link
- `prefers-reduced-motion` — анимации отключаются
- версия для печати

## Мелкие правки своими руками

| Что | Где |
|---|---|
| Цвета | `css/styles.css`, блок `:root` в самом начале |
| Номер WhatsApp | `index.html` (поиск `77479112195`) + `WA_PHONE` в `js/main.js` |
| Тексты кнопок WhatsApp | параметр `?text=` в ссылках `wa.me` |
| Список услуг | блок `<!-- SERVICES -->` в `index.html` |
| Шаги работы | блок `<!-- PROCESS -->` |
| Вопросы FAQ | блок `<!-- FAQ -->` — **и продублируйте в JSON-LD внизу файла**, иначе разметка разойдётся с текстом |
